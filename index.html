Notice d'utilisation

Comprendre le simulateur et optimiser vos personnages

1. Importation

Le simulateur utilise l'API Enka.Network pour récupérer vos données en temps réel.

Prérequis en jeu

  • Menu Paimon > Modifier le profil.
  • Activez "Afficher les détails des personnages".
  • Placez les personnages dans votre Vitrine.
  • Attendez 2-5 min après la déconnexion pour la mise à jour serveur.

2. Comprendre le Score

Le simulateur de guoba.gg se base sur 3 métriques différentes pour évaluer vos builds.

Le Score

Le score est un système hybride :

  • Valeur de Base : Chaque "Roll" parfait (ex: 7.8% DGT Crit) vaut une fraction de point.
  • Pondération : Ces points sont multipliés par un "poids" (défini dans config.js). Exemple : La Défense aura un poids de 1 pour Chiori, mais de 0 pour Arlecchino.
  • Bonus Mainstat : L'algorithme prend en compte la pertinence de la statistique principale des pièces variables (Sablier, Coupe, Diadème).
  • Multiplicateur de Set : Un bonus est appliqué si le joueur possède le Set Best-in-Slot (BiS) recommandé.

La Note

La note représente la chance qu'a eu le joueur dans les substats de ses artéfacts.

La note est calculée selon le nombre de Rolls Utiles (améliorations tombées sur des stats pertinentes pour ce personnage précis).

Chaque team de chaque personnage a un plafond théorique. Ce plafond est divisé en plusieurs tiers proportionnels correspondant à des lettres.

L'Efficacité

Efficacité : Votre puissance actuelle vs votre potentiel théorique max.

RNG : Votre chance. Un score élevé signifie que vous obtenez souvent des valeurs hautes lors des améliorations.

3. Analyse & Conseils

Stats Mortes : Points perdus dans des stats inutiles (ex: DÉF sur un DPS).

Pièce Joker (Off-Set) : Le simulateur vérifie si votre 5ème pièce (hors-set) est assez puissante pour justifier sa place. Elle doit être bien meilleure que vos pièces de set.

4. Simulateur de Reroll

Estime la rentabilité d'utiliser l'Offrande Mystique (Strongbox) sur un artéfact.

Risque Élevé Potentiel Élevé

Conseil : Ne recyclez jamais une pièce "Solide" ou "Déconseillée".
